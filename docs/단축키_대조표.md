# 서일 오피스 — 한글 2024 단축키 대조표 (2026-11-02)

기준: 한컴 공식 도움말 단축키 일람(help.hancom.com, hoffice130 Hwp `view/toolbar/shortcut(table).htm`) + 메뉴별 페이지(file·edit·view·insert·format·Page·table·tools).
구현: rhwp-studio v0.8.7 기본 단축키 + 이음오피스 `hancom-keys` 플러그인(빌드에 포함) + hwp-pad 패치(`patches/hancom-web.mjs`, 2026-11-02).

## 정리
- 한글 핵심 편집 키는 사실상 전부 들어 있고, **표 작업의 Ctrl+N 계열은 단축키 모드에서만** 된다(브라우저 구조상 불가피, Tauri 앱에서 해소 예정).
- 이번 패치로 메운 것: 파일 Alt 키 4종, 셀 블록 Ctrl+E/C/X·Ctrl+Shift+S(이음이 Electron 메인 프로세스에 맡겼던 부분), Ctrl+J, Ctrl+Shift+W/Q, Ctrl+Shift+Insert/Delete, Ctrl+G,Z.
- 남은 ✖는 rhwp에 기능 자체가 없는 것(여백 조절 키, 글꼴 순환, 구역 나누기, 골라 붙이기 등). 필요해지면 rhwp 명령부터 만들어야 한다.
